# Agent instructions

Rules for any AI agent or coding assistant working in this repository.

## No AI attribution

Leave no trace that an AI tool wrote or helped write anything. This covers
every artifact that leaves your hands:

- commit messages -- no `Co-Authored-By:` trailers naming an AI, no
  "generated with" lines
- pull request titles, descriptions and comments
- code, comments, documentation, test fixtures and data files
- branch names and tags

No watermarks, footers, badges, emoji signatures or links to AI products,
in any form. Write as the repository's author would.
